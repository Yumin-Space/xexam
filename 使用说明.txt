Xexam 使用说明
====================
更详细的架构图、截图和「更新日志」都在 README.md 里；每次更新也只在那里记录版本。
镜像标签：latest = 最新；v0.2.2 这类 = 固定版本（想锁定版本就把 docker-compose.yml 里的 :latest 改成 :v0.2.2；镜像从 v0.2 起发布，没有 v0.1）。
每个版本在 GitHub 仓库的 Releases 页也有一条说明（构建成功后自动生成）。
镜像同时支持 x86（amd64）和 ARM（arm64），在哪种机器上拉取都会自动选对。

一、怎么启动
  方式 A：直接拉取 GitHub 自动构建好的镜像（推荐，任何装了 Docker 的机器都行）
    每次把代码推送到 GitHub 的 main 分支，GitHub Actions 会自动构建镜像、跑一遍冒烟测试，通过后发布到
        ghcr.io/yumin-space/xexam:latest
    测试不通过就不会发布。在 GitHub 仓库的 Actions 页面能看到每次的结果。
    用法：只需要仓库里的 docker-compose.yml 这一个文件（复制到任意文件夹即可，不需要其他代码）。
      1. 打开 Docker Desktop，等它显示 Running。
      2. 第一次登录（镜像是私有的，所以要登录一次）：
             docker login ghcr.io -u Yumin-Space
         密码处填一个有 read:packages 权限的 GitHub 令牌（Settings → Developer settings → Personal access tokens）。
      3. 在 docker-compose.yml 所在的文件夹里运行：
             docker compose up -d
      4. 浏览器打开  http://localhost:8765
    容器名和镜像名都叫 xexam。数据放在 Docker 的命名卷 xexam_data 里（不是你电脑上看得见的文件夹）。
    更新到最新版本：docker compose pull 然后 docker compose up -d
    停止：docker compose stop      再启动：docker compose start

  方式 A2：从源码构建（改代码时用，需要完整的仓库代码）
    docker compose -f docker-compose.build.yml up -d --build

  方式 B：不用 Docker
    双击 start.bat（需要电脑里装有 Python 3.8 或更新版本）。数据同样放在本文件夹的 data 里。

二、第一次使用：导入题库
  程序不再读取 Excel，题库和学习记录都保存在 SQLite 数据库里（data/xexam.db）。
  所以第一次要把 Excel 传进去：
    1. 首页点「题库管理 / 上传 Excel」（题库为空时首页中间也有「去上传题库」）。
    2. 选择你的 Excel 题库文件（.xlsx，也可以把文件拖到虚线框里）。
    3. 先看「检查结果」：新增几题、更新几题、下架几题、哪几题读不出来（会写明原因）。
    4. 确认没问题，点「确认导入」。点之前不会写入任何东西。
  如果有旧版留下的 progress.json，第一次启动时会自动把里面的成绩和错题记录迁移进数据库（只迁移一次）。
  用 Docker 时，要先把 progress.json 放进卷里再重启，具体命令见 README.md 的「迁移旧版的学习记录」。

三、以后怎么更新题库
  1. 在电脑上用 Excel 修改你的文件：新增工作表、新增或修改题目都可以。
  2. 保存后，在「题库管理」里把整份 Excel 重新上传，看检查结果，确认导入。
  注意：上传的文件会被当成「完整的题库」。
    - 文件里新出现的题 → 新增；改过的题 → 更新；
    - 文件里没有的题 → 下架（不再出现在考试里）。导入前会弹窗提醒，传错文件时选「回去检查」就不会有任何改动。
    - 下架的题，答题记录会保留。以后再把这道题传回来，会自动恢复，错题本也跟着回来。
    - 如果你修改了某道题的题干，程序会把它当成一道新题（旧题下架，旧题的答题记录不会带到新题上）。只改选项、答案、解析、翻译，则算「更新」，记录不受影响。

四、怎么考试
  1. 首页勾选要考的工作表，选「全部题目」或「错题本」，设置题数，点「开始考试」。
  2. 答题过程中不会显示对错，也不显示分数。可以随时跳题、标记不确定的题。
  3. 点「交卷」后才计分（答对的百分比），并列出每道错题的：
     你的答案、正确答案、解析（怎么选）、记忆口诀、中文翻译。
  4. 热点题有多个小项，每个小项都选对才算这题答对。
  5. 没做完可以点「暂存退出」，下次打开首页会出现「继续作答」（这个暂存放在浏览器里，换浏览器就没有了）。
  6. 答题时，题目右上角有「日语 / 中文」两个按钮，随时点着对照。
     中文用的是 Excel 里 B 列的翻译；切换只换文字，选项字母、已选的答案、计时都不受影响，判分也不变。
     选项本身（はい / いいえ、Apple 这类答案原文）不翻译。你选的语言会被记住。
     如果某道题 B 列没写翻译，或者翻译里的选项、小项数量和 A 列对不上，这道题的「中文」按钮会置灰。

五、Excel 题库格式（和你现在的 Excel 完全一样）
  A 列：题目
        选择题：题干后空一行，选项写成「A. 内容」，一行一个。
        热点题：第一行写 ホットスポット，小项写成「1. 内容　はい / いいえ」。
  B 列：中文翻译（可以不写；写的话请和 A 列保持同样的结构：选择题的选项也写成「A. 内容」，
        热点题的小项写成「1. 内容」，这样答题时才能切换成中文）
  C 列：以「【答案】」开头，后面可以接「【解析·怎么选】」「【记忆口诀】」。
        单选/多选：【答案】C 或 【答案】C、E
        热点题：  【答案】1 是；2 否；3 是
                  小项的答案可以写「是/否」「はい/いいえ」，
                  或者直接写选项文字（比如 Apple）。
  一行一道题。读不出来的题，会在上传后的检查结果里写明是哪个工作表第几行、什么原因。

六、错题本
  答错的题会进入错题本。之后在错题本里连续 2 次答对，就自动移出。
  首页选「错题本」可以只练这些题；交卷后也可以点「只重做错题」。

七、数据放在哪里、怎么备份
  用 Docker：全部数据（题库 + 成绩 + 错题记录）都在 Docker 命名卷 xexam_data 里的 xexam.db。
    更新镜像、docker compose down、删除并重建容器，数据都还在。
    千万不要运行  docker compose down -v ，-v 会把卷一起删掉，数据就没了。
    备份和恢复的命令见 README.md 的「备份和恢复」。
  不用 Docker（start.bat）：数据在本文件夹的 data 里，备份就是停止程序后复制整个 data 文件夹。
  程序只绑定本机（127.0.0.1），不联网，不会把你的题目发送到任何地方。

八、让手机/平板也能用（可选，注意安全）
  页面已经适配 iPhone（按钮够大、避开刘海和底部横条、翻页栏固定在屏幕底部）。
  在 iPhone 的 Safari 里打开后，点分享按钮 →「添加到主屏幕」，之后像独立应用一样全屏打开。
  这个程序没有登录。默认只有本机能访问。如果要在同一个家庭 Wi-Fi 里用手机：
    1. 在 docker-compose.yml 旁边新建一个叫 .env 的文件，写两行：
           XEXAM_BIND=0.0.0.0:8765
           XEXAM_ALLOWED_HOSTS=你的电脑的局域网IP        （例如 192.168.1.20）
    2. docker compose up -d
    3. 手机浏览器打开  http://你的电脑IP:8765
  只在你信任的家庭网络里这样做；咖啡厅、公司网络请不要开。
  想在外面（不在家里的网络）用：走 Cloudflare Tunnel + Cloudflare Access，步骤见 README.md 的
  「通过 Cloudflare Tunnel 从互联网访问」。不要直接把端口开到互联网上。

九、常见问题
  - 提示「连不上服务」：确认 Docker Desktop 在运行、容器是启动状态（docker compose ps）。
  - 8765 端口被占用：在 .env 里写  XEXAM_BIND=127.0.0.1:8766  ，docker compose up -d，然后访问 8766。
  - 上传时报「不是有效的 .xlsx」：在 Excel 里选「另存为」→「Excel 工作簿(.xlsx)」。带密码的文件要先去掉密码。
  - 导入前预览里有「读不出来」：展开看原因，多半是 C 列没写「【答案】…」，或答案字母不在选项里。
